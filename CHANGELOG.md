# Changelog

## 0.1.0

- First release, with the core actions of the shared Wordsmith automation catalogue: ask an agent, get an answer, upload and get files, redline, compare and convert documents, review a document, find a review, draft a document, create, update, comment on, attach files to and find tasks, and get a job.
- Wordsmith Trigger (webhook endpoints) and Wordsmith Polling Trigger.
- Two credentials: Wordsmith OAuth2 API (PKCE, recommended) and Wordsmith API (API key), picked in each node's Authentication field.
